# Стоматологическая видеотека — веб-версия

Открыть: https://saidlekvio-sys.github.io/videoteka/

Видео, книги и материалы берутся из публичной папки на Яндекс Диске и воспроизводятся прямо оттуда.
Данные пользователя (прогресс, карточки, конспекты, пометки) хранятся в браузере или в аккаунте — в этом репозитории их нет.

На iPhone/iPad: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
